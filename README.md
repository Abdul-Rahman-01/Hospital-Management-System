# Hospital Management System

## Project Description
This is a Java-based Hospital Management System developed to manage patient details, doctor information, appointments, and billing using MySQL and JDBC.

## Features
- Patient registration
- Doctor management
- Appointment scheduling
- In-patient and out-patient management
- Billing system

## Technologies Used
- Java
- JDBC
- MySQL
- HTML
- CSS

## How to Run
1. Download or clone the repository
2. Open the project in Eclipse or IntelliJ
3. Configure MySQL database
4. Run the main Java file
